Questo è il primo codice che si scrive quando si inizia a programmare in Java.
Serve per capire la struttura base che ogni programma deve avere. 

                        
public class Main{ 
    public static void main (String[] args){ 
        System.out.println();
    }
}

Spiegazione dettagliata

                        
public class Main
Questa riga crea una classe chiamata Main.
In Java, tutto il codice deve essere scritto dentro una classe.
La parola chiave public significa che la classe è visibile ovunque.
Il file che contiene questo codice deve chiamarsi Main.java, ovvero con lo stesso nome della classe.
Le parentesi graffe { } che seguono racchiudono tutto il contenuto della classe.
Tutto ciò che scrivi dentro queste parentesi appartiene alla classe Main. 

                        
public static void main (String[] args)
Questa è la parte più importante del programma. È il punto di ingresso del programma Java: quando esegui il programma, la prima cosa che viene eseguita è questo metodo. Vediamo ogni parola:
  • public: e' un modificatore di accesso, che in questo caso, il metodo è accessibile da fuori.
  • static: appartiene alla classe e non a un oggetto.
  • void: non restituisce nessun valore.
  • main: è il nome del metodo, obbligatorio.
  • String[] args: è un parametro che può contenere argomenti passati da terminale.
Le parentesi graffe del metodo { } racchiudono il codice che verrà eseguito quando il programma parte. System.out.println();
Questa istruzione serve per stampare qualcosa sullo schermo. In questo caso le parentesi sono vuote, quindi non stampa nulla, ma se scrivi: 
                        
System.out.println("Ciao!");
Il programma stamperà:

Ciao!

I dati, in qualsiasi linguaggio di programmazione, sono come delle scatole con all'interno un valore.
Possono essere: dichiarate e assegnate

Cosa vuol dire dichiarare un dato?
Dichiarare un dato, in termini semplici, e' come creare una scatola a tuo piacimento, dove puoi metterci un contenuto, questo contenuto puo' essere di tanti tipi diversi, questo in informatica viene chiamato tipo di dato.

Cosa vuol dire assegnare un valore a un dato?
Assegnare un valore a un dato, in termini semplici, e' inserire il valore a questa scatola, ma ovviamente deve rispettare il tipo di dato.

Il tipo di dato puo' essere:
  • int: ovvero un numero intero tipo: 1 oppure 2, un numero che non ha numeri dopo la virgola.

  • float: ovvero un numero decimale tipo: 3.14 oppure 4.4444444, un numero che in questo caso ha i numeri dopo la virgola con un massimo di 7 numeri dopo la virgola.

  • double: stessa cosa del float ma con un massimo di 15 numeri dopo la virgola.

  • boolean: questo invece puo' essere solo true o false, ovvero tra true(vero) e false(falso), come il si e il no.

  • char: questo per indicare che il dato racchiude un carattere solo, tipo 'a', e viene racchiuso tra gli apostrofi (')

  • String: ovvero un insieme di char, ovvero un insieme di caratteri che possono formare una frase o una parola qualsiasi, che vengono racchiusi con le doppie virgolette ("), ovvero cosi': "messaggio", pero' non e' un tipo di dato PRIMITIVO come gli altri detti in precedenza, ma ben si' una classe, nelle lezioni successive parlero' delle classi e oggetti in modo piu' approfondito.

Dopo aver detto cos'e' un dato e cosa sono i tipi di dati, dobbiamo capire come possiamo dichiarare/assegnare un dato in Java.

Mettiamoci in testa questa sintassi qua:
  • tipodiDato nomedeldato;
    Per la dichiarazione.


  • nomedeldato = valore;
    Per assegnare un valore al dato.


  • tipodiDato nomedeldato = valore;
    Dichiarazione e assegnare nella stessa riga.

Un esempio di sintassi in Java puo' essere:

Dichiarazione:
int x;
float pi;
double pi_lungo;
boolean nome;
char carattere;
String parola;

Assegnazione:
x = 100;
pi = 3.1415926;
pi_lungo = 3.141592653589793;
nome = true;
carattere = 'a';
parola = "pippo";

Dichiarazione e assegnazione:
int x = 100;
float pi = 3.1415926;
double pi_lungo = 3.141592653589793;
boolean nome = true;
char carattere = 'a';
String parola = "pippo";

Nel codice verra' scritto cosi': 
                        
public class Main {
    public static void main(String[] args) {
        int x = 100;
        float pi = 3.1415926;
        double pi_lungo = 3.141592653589793;

Tutto cio' NON e' stato fatto per farvi studiare a memoria la sintassi, ma per capire la struttura della sintassi.
E' stato fatto per dimostrare che non cambia niente per ogni tipo di dato che si vuole usare, l'unica cosa che cambia e' il valore, che varia ovviamente dal tipo di dato assegnato.

Convenzione


Come si nomina un dato?
Un dato puo' essere chiamatato come si vuole, ma solo fino a un certo punto.

Un dato NON puo' essere nominato con dei simboli speciali prima del nome, tipo: #nome
NON puo' essere nominato con i numeri prima del nome, tipo: 5nome
e NON puo' essere nominato nemmeno con della punteggiatura prima del nome, tipo: !nome oppure .nome

Un dato deve rispettare una certa logica nel nome, senza essere troppo esagerati e senza essere troppo minimali.
Un dato NON va' nominato cosi': float ilvotocheprendoascuolanellaverificadimatematica;
Sarebbe meglio scriverlo cosi': float votoverificamatematica;
Ma se noti non e' cosi' intuibile, mentre si legge il codice nella ricerca di un errore puo' sfuggire di mano il significato di una variabile del genere, questa cosa si puo' sistemare con una convenzione di naming.

Per fare questo bisogna nominare un dato con la convenzione camelCase, tipo cosi': float votoVerificaMatematica;
Oppure come altra convenzione c'e' la snake_case, questo puo' essere un esempio: float voto_verifica_matematica;
C'e' anche la PascalCase, esempio: float VotoVerificaMatematica;
C'e' anche la SCREAMING_SNAKE_CASE, esempio: float VOTO_VERIFICA_MATEMATICA;

Quale dei tanti si deve usare in Java?
Per rispondere a questa domanda bisogna introdurre un concetto fondamentale della programmazione...
Ovvero lo stato di un dato, che puo' essere variabile o costante.

DIFFERENZA TRA VARIABILE E COSTANTE

La differenza tra variabile e costante:
  • Una variabile puo' cambiare valore durante l'esecuzione del codice.
  • Una costante non puo' cambiare valore nel codice, e se si tenta di modificarlo si otterra' un errore.
                        
public class Main {
    public static void main(String[] args) {
        int x = 100;
        final float PI = 3.1415926;
    }
}
Il dato x e' una variabile, perche' NON ha la parola chiave final.
Il dato PI e' una costante, perche' ha la parola chiave final.

Le variabili con più parole vanno scritte in camelCase o snake_case.
Le costanti vanno scritte in SCREAMING_SNAKE_CASE.
Il PascalCase invece si usa solo per le classi.

Casting

Dopo aver parlato di com'e' strutturato un dato in informatica, dobbiamo capire come possiamo usarlo in modo efficace.
Per manipolare bene un dato bisogna prima parlare del casting.

Cos'e' il casting?
Il casting è il cambio tra un tipo di dato e un altro tipo.
Esempio: cambiare un dato int a un float.

Ma il casting puo' essere di due tipi, Downcasting e Upcasting.
Tutto cio' dipende dai tipi di dati che si danno alle variabili, proprio perche', come citato in precedenza, ogni tipo di dato ha il suo peso in memoria.
Tabella utile per questo argomento:
Tipo di dato Memoria (byte)
double8
float4
int4
String2 (per ogni carattere)
char2
boolean1
Parliamo dell'Upcasting, ovvero convertire un tipo piu' piccolo a uno piu' grande. 
                        
public class Main {
    public static void main(String[] args) {
        float a = 100.23456;
        double b = a;
    }
}
In questo caso, stiamo assegnando alla variabile b il valore di a, dove a (float) e' piu' piccolo di b (double).
L'upcasting è automatico e non richiede una sintassi particolare.

Parliamo del Downcasting, ovvero convertire un tipo piu' grande a uno piu' piccolo. 
                        
public class Main {
    public static void main(String[] args) {
        double a = 100.234567891;
        float b = (float)a;
    }
}
In questo caso, la conversione avviene con (float) accanto alla variabile a.
Il downcasting richiede una sintassi esplicita.

Consiglio: evitare conversioni con String, dato che non è un tipo di dato primitivo.

Un programma, come abbiamo visto in precedenza, viene fatto con una classe Main e con dei dati costanti o variabili.
Nella programmazione c'e' uno dei concetti piu' fondamentali della programmazione, che sono le condizioni, oppure chiamate "Strutture di controllo condizionali".

A che servono e come si usano?
Le strutture di controllo sono delle parti di codice che vengono eseguite se la condizione e' vera.

Un esempio molto semplice che possiamo fare e' questo:
Controllare se la variabile intera eta sia maggiore o uguale a 18, praticamente controlliamo se e' maggiorenne o no.

Ma come si fa sottoforma di codice?
Prima di tutto, dobbiamo conoscere tutte e tre le strutture di controllo condizionali, dopo di che' sapere tutti gli operatori di controllo.

Partiamo dalle strutture di controllo:

  • if (condizione) {codice}, e' l'istruzione condizionale, ovvero che se la condizione all'interno delle parentesi tonde, e' vera(true), esegue il blocco di codice all'interno delle parentesi graffe. Ed e' la primissima struttura tra le tre che si va a scrivere.

  • else if (condizione) {codice}, questo e' uguale all'if, solo che vengono scritti sotto l'if e sopra l'else, e possiamo scriverne piu' di uno e vengono eseguiti se la condizione dell'if e' falsa (false), ovvero che non viene eseguito il codice all'interno dell'if.

  • else {codice}, questa e' una struttura condizionale che viene eseguita se tutti gl'if ed else if non vengono eseguiti. (OPZIONALE, se non serve e' meglio non scriverlo.)

Premessa, successivamente ci saranno esempi di codice, se non si riesce a capire bene la distinzione tra if, else if, ed else, e' normale, piu' avanti ti sara' tutto piu' chiaro con gli esempi di codice.
E ora ci sono gli operatori di controllo:
Operatori di controllo Cosa vuol dire
== Uguale a
!= Diverso
> Maggiore
< Minore
>= Maggiore o uguale
<= Minore o uguale
Ora che abbiamo queste informazioni, possiamo provare a fare l'esempio che ho fatto prima, ma sottoforma di codice.

Codice d'esempio (Codice piccolo): 
                        
int eta = 18;

if (eta >= 18 ) {
    System.out.println("Sei maggiorenne!");
}
else {
    System.out.println("Sei minorenne!");
}
Output:
Sei maggiorenne!

Codice d'esempio (Codice con il Main ecc..): 
                        
public class Main {
    public static void main(String[] args) {
        int eta = 18;

        if (eta >= 18 ) {
            System.out.println("Sei maggiorenne!");
        }
        else {
            System.out.println("Sei minorenne!");
        }
    }
}
Output:
Sei maggiorenne!

In questo caso viene eseguito solo l'if con eta >= 18, di conseguenza viene stampato solo Sei maggiorenne!, ma ci sono altri casi dove c'e' bisogno anche dell'else if.
